# Website Technologies

- **Next.js + React:** Build the website and its pages.
- **TypeScript:** Makes code easier to check.
- **CSS:** Styles, colours, and layouts.
- **Three.js:** Interactive 3D visuals.
- **GSAP:** Animations.
- **Lenis:** Smooth scrolling.
- **Resend:** Sends enquiry emails when configured.
- **Mona Sans:** Website font.
